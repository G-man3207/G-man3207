I build systems that stay correct under chaos. Lately that means [Kronik](https://github.com/G-man3207/Kronik): a deterministic runtime where stateful Wasm actors record every external effect, so you can fork production traffic, replay it through new code, and promote only when the behavior diff says yes.

I like the unglamorous parts of reliability: kill-9 recovery, privacy/erasure, DST, and tooling you can run on a single VPS. Background in platform engineering, browser privacy, and shipping agentic workflows that have to survive contact with real infrastructure.
